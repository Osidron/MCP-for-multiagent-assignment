# Сценарий защиты

1. `./run.ps1`. Показать схему Host / Client / Server в README.
2. Найти Fortamet или метформин, выбрать SPL, показать противопоказания, дату/версию, открыть инструкцию. При FDA 403 объяснить отдельный статус недоступности.
3. Stdio → обнаружить → BMI: 70 кг, 175 см → подтвердить → 22.86. Инспектор: initialize, initialized, tools/list, tools/call и ответ с тем же id.
4. Ввести отрицательную массу: структурированная ошибка без падения Host.
5. SSE → GCS: E4 V5 M6 = 15; показать enum, затем checkbox CHA2DS2-VASc. Объяснить NT и отсутствие фиктивной суммы.
6. Внешний PubMed → search_articles → query `10.1056/NEJMoa2102953`, max_results 1 → PMID 34554658 и ссылка. Повторить и показать TTL-кэш без нового обмена.
7. С MCP_AUTO_START=0 остановить ручной SSE-сервер, вызвать инструмент, показать ограниченную ошибку соединения; снова запустить сервер.

# Ответы на контрольные вопросы

1. **MCP и REST/OpenAPI.** REST задаёт ресурсы и HTTP-операции; OpenAPI описывает HTTP-контракты. MCP определяет JSON-RPC методы, согласование версии/возможностей, обнаружение инструментов с JSON Schema, результаты, ошибки и уведомления. Host содержит клиентов, каждый подключается к серверу. MCP может использовать HTTP, но произвольный REST endpoint не является MCP. LLM для Host не обязателен.
2. **Почему нельзя print в stdout.** Stdio передаёт JSON-RPC через стандартные потоки; диагностическая строка ломает разбор. Логи идут в stderr, stdout обслуживает SDK.
3. **Сообщения.** Initialize: `{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"host","version":"1"}}}`. Ответ с тем же id содержит protocolVersion/capabilities/serverInfo; затем notifications/initialized без id. Вызов: `{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"bmi","arguments":{"weight_kg":70,"height_cm":175}}}`. Ответ содержит result.content; ошибка инструмента — isError, протокольная — error. Фактические сообщения видны в инспекторе.
4. **SSE и stdio.** SSE допускает несколько клиентов независимого процесса, удобен для команды врачей; требует порта, HTTP-сессий, контроля доступности, таймаутов и при удалённом доступе TLS/аутентификации. Stdio проще изолировать и закрыть вместе с клиентом, но обычно нужен процесс на клиента. SSE реализован буквально по PDF; внешний endpoint использует Streamable HTTP.
5. **Защита от галлюцинаций.** Формулу считает код. Сервер проверяет строгую схему, границы, единицы, не заменяет пропуски нормой. Пользователь подтверждает форму; методика версионирована, контрольные случаи тестируются. Вывод содержит компоненты/ограничения; внешние тексты являются данными. СКФ не превращается автоматически в разрешение препарата.
