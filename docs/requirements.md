# Матрица текущей версии

| Возможность | Реализация | Проверка |
|---|---|---|
| Вариант 1 | официальный SDK 2.3.0, 3 расчёта и каталог через stdio | реальное initialize/list/call/error |
| Вариант 2 | отдельный SSE, /sse и /messages/, 5 расчётов и каталог | реальный процесс и отказ после остановки |
| Вариант 3 | удалённый PubMed MCP через HTTPS | обнаружение и поиск публикации |
| Формы и Sanitizer | JSON Schema, числа, enum, checkbox, обязательные поля | UI и тесты ввода |
| Инспектор | ObservedStream, идентификаторы и время | сопоставление ответа с SDK |
| Материалы | README, IDE-конфиг, руководство, презентация | обновлены по текущему объёму |

По новому запросу пользователя лекарственный функционал удалён из второй работы. Первый проект сохранён отдельно. Набор текущей версии сознательно отличается от первоначального расширения первой работы.
