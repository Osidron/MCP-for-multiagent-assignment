# Матрица соответствия

| Требование | Реализация | Проверка / ограничение |
|---|---|---|
| Сохранить первую работу | отдельный clone, копия drug_search | исходный репозиторий не редактировался |
| SDK 2.x, stdio, 3 расчёта | server.py, mcp 2.3.0 | test_protocol: реальный запуск/list/call/error |
| Метаданные и формулы | calculators.py, list_calculators | методы, единицы, диапазоны, ограничения, ссылки |
| Независимый SSE | /sse и /messages/ | отдельный процесс, реальное соединение |
| ≥5 по направлениям | 5 расчётов + каталог + 4 лекарственных tools | 10 инструментов tools/list |
| Sanitizer | sanitizer.py | запятая, пробелы, типы; без выдуманных норм |
| Таймауты/повторы/закрытие | client.py, lifecycle.py | connection refused после остановки, процесс завершён |
| Внешний MCP | PubMed Anthropic | initialize/list/search/metadata без ключа |
| 10–15 с и TTL | общий 12 с, TTL 300 с | живые вызовы около 1.4 с |
| Русский поиск | Bergamot и лекарственные адаптеры через MCP | первый запрос требует скачивания модели |
| Выбор/версии/ссылки | лекарственная панель, get_contraindications | живой DailyMed; FDA возвращает 403 |
| Динамические формы | фактический JSON Schema | number, enum, checkbox; массивы через JSON |
| Интерпретация | карточка/компоненты/источник | нейтральное оформление согласно уточнению пользователя |
| Настоящий инспектор | ObservedStream send/receive | тест сверяет id и content с SDK |
| Одна команда и IDE | run.ps1, .cursor/mcp.json | запуск выполнен |
| Сдача | README и docs | презентация PDF не требуется |
| GitHub и Cloud | целевой репозиторий и публичное приложение | опубликовано; публичный сценарий и все три MCP-варианта проверены, см. verification.md |
